# QR·QR

Локальный веб‑сервис для обмена файлами и текстом между компьютером и телефоном. Без аккаунтов, облачного хранилища и нативного приложения.

## Что уже есть в MVP

- QR‑код для быстрого подключения телефона;
- двусторонняя отправка нескольких файлов;
- скачивание и удаление файлов из сессии;
- общий текстовый буфер с автоматической синхронизацией;
- индикатор подключённых устройств;
- адаптивный интерфейс для компьютера и телефона;
- автоматическое удаление неактивной сессии через 2 часа;
- ограничение одного файла до 200 МБ и сессии до 400 МБ.

Данные хранятся только в оперативной памяти процесса, который запущен на компьютере. Перезапуск сервера очищает все сессии и файлы.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

В терминале появятся адреса `Local` и `Network`. На компьютере откройте именно адрес `Network`, например:

```text
http://192.168.1.42:3000/
```

На странице появится QR‑код. Телефон должен быть подключён к той же Wi‑Fi сети. Отсканируйте QR‑код обычной камерой и откройте ссылку.

Для режима без горячей перезагрузки:

```bash
npm run build
npm start
```

## Если телефон не подключается

- Проверьте, что на компьютере открыт адрес `Network`, а не `localhost`.
- Разрешите Node.js входящие подключения, если система покажет запрос брандмауэра.
- Убедитесь, что оба устройства в одной сети, а в роутере не включена изоляция клиентов или гостевая сеть.
- VPN на одном из устройств может мешать локальному подключению.

## Проверка

```bash
npm test
```

Тесты собирают production‑версию и проверяют создание сессии, подключение двух устройств, синхронизацию текста, загрузку, скачивание и удаление файла, а также ограничения ошибок.

## Техническая схема

Интерфейс сделан на React и vinext. Локальный сервер обслуживает страницу и API на одном порту. Клиенты отправляют heartbeat раз в 1,5 секунды и получают актуальное состояние сессии. Файлы и текст не покидают локальный процесс и не сохраняются на диск.
